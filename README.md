## Local Development

### Prerequisites

- Node.js (v18+)
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Ankush-learning/PORTFOLIO.git
```

Navigate into the project:

```bash
cd PORTFOLIO
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL displayed in your terminal.

### Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
